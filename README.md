# Taller Virtual · Herramientas del aula

Portada de **https://jsalsal003.github.io/** con las herramientas para Tecnología y Digitalización (TyD) y Computación y Robótica (CyR):

- **AulaCAD 3D** (diseño 3D y exportación a STL): https://jsalsal003.github.io/aulacad/
- **Editor HTML** (páginas web con resultado al momento): https://jsalsal003.github.io/editor-html/
- **Vistas 3D** (alzado, planta y perfil de piezas de cubos): https://jsalsal003.github.io/vistas3d/
- **Placa virtual** (programación por bloques sin placa): https://jsalsal003.github.io/placa/
- **Plano 2D** (dibujo técnico a escala y acotación): https://jsalsal003.github.io/plano2d/
- **Casa 3D** (viviendas e interiores en 3D): https://jsalsal003.github.io/casa3d/

Funcionan en Chromebook y Linux, sin cuenta y sin instalar nada. Este repositorio se actualiza con `publicar.sh` desde la carpeta de trabajo.
